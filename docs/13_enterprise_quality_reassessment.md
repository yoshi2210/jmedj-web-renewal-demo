# v5: 医療従事者向けエンタープライズ品質の再評価

## 結論

既存のデモは検索・4事業ゾーン・モバイル導線を改善しているが、医師が短時間で情報を判断に使うための「鮮度・種別・利用上の境界」が画面上で弱かった。v5は装飾を増やすのではなく、情報の意味と対話の確実性を補強する改訂である。

この文書の観測対象は本リポジトリのモックコードのみであり、実サイトへの追加調査や未許可のテストは行っていない。

## 監査結果と対応

| 優先度 | 課題 | 影響 | v5対応 |
|---|---|---|---|
| P0 | 臨床情報の利用文脈が弱い | 急ぐ利用者が情報の鮮度・用途を読み飛ばしやすい | トップに情報利用の案内を置き、本番で必要な編集メタデータを明示 |
| P0 | 共通カードの日付の意味が不明確 | 何の、いつの情報か比較しづらい | `掲載`／`公開`／`刊行`をコンテンツ種別ごとに表示し、`time`要素を出力 |
| P1 | 入口が事業者都合 | 利用目的からの選択がしづらい | 診療・学習・キャリアの目的別導線を追加 |
| P1 | 検証UIが常時露出 | 提案画面が未完成な印象になる | 状態切替を折りたたみの品質確認項目へ退避 |
| P1 | 検索候補とモバイルメニューの支援技術対応が不十分 | キーボード利用時に現在位置を失いやすい | `aria-activedescendant`、モーダル属性、フォーカストラップと起点復帰を実装 |

## 実装内容

### v6: 出版社の来歴を残した単色デザイン

- 白`#FFFFFF`を基本面、新報藍`#174A7E`を唯一の主色として定義した。
- グラデーション、緑・紫・橙のゾーン色、強い影、カードの浮き上がりを廃止した。
- 明朝は編集見出し、ゴシックは操作と本文、Manropeは日付・価格に限定した。
- 紙面の罫線を再解釈した藍の縦罫を、ヒーローと目的別入口の共通シグネチャにした。
- 情報構造や新しいコンポーネントは増やさず、既存の画面・データ・操作を維持した。

1. **トップページ**: 主題を「検索する」から「診療の判断に必要な情報を確かめる」へ変更。カテゴリ導線の後に利用目的別の入口を追加した。
2. **全カード**: 記事は「記事を読む」、動画は「動画を見る」、求人は「募集を見る」、物件は「物件を見る」と行動名を具体化。著者等に加え、種別に応じた日付を表示する。
3. **検索結果**: 「横断検索」「種別で絞り込み」「日付を明示」の3原則を画面上に示し、無関係な広告を結果へ混在させないことを品質要件として明文化した。
4. **アクセシビリティ**: モバイルメニューに明示的な閉じる操作・フォーカス移動・Tab循環を追加。検索候補はcombobox/listbox関係を同期する。

## 本番実装で必須にする情報モデル

| 項目 | 対象 | 要件 |
|---|---|---|
| 公開日／改訂日 | 記事・動画・求人・物件 | ISO日付を保持し、カードと詳細で表示する |
| 刊行日・版 | 書籍・電子 | 初版・改訂版を別フィールドにする |
| 執筆者・監修者 | 記事・動画・書籍 | 人物IDと役割を構造化して表示する |
| 根拠の種別 | 臨床系記事 | 編集部が付与した「ガイドライン解説」「総説」等のみを表示する |
| 訂正・更新告知 | 全コンテンツ | 公開状態と連動して明確に配信する |

デモには実データの監修・根拠情報がないため、存在しない「監修済み」「最新」は表示しない。トップの案内は、本番で必要な要件を示すものとする。

## 実装移行の受入基準

- 全詳細に種別、公開／改訂日、責任主体がある。臨床系には根拠種別と注意情報もある。
- 検索に無関係な広告を混在させず、読み込み・0件・通信失敗に復帰行動がある。
- 記事検索、書籍購入、求人検索はキーボードだけで完結する。
- 内部リンク・静的アセット、`lang`、`title`、主要ランドマークを自動検査する。
- 編集ガバナンス、検索ログの適法な利用、個人情報の保持期間・権限・監査ログを別途合意する。
