# v8: 公開コンテンツの静的同期と「本日の編集面」

更新日: 2026-07-25

## 目的

提案サイトを架空の文言だけで評価する状態から進め、実際の新刊・記事・動画・
お知らせが新しい情報設計の中でどう見えるかを検証する。同時に、本番サイトへ
閲覧者ごとの通信を発生させず、日本医事新報社の老舗医学出版社としての信頼感を
損なわないトップページ表現へ更新する。

## 取得範囲と負荷制御

サイトオーナーの許可を前提に、`tools/sync_public_content.py` が公開情報だけを
更新時に取得する。ブラウザから本番サイトのAPIを直接呼ぶ実装にはしていない。

- 新刊: `/collections/paper-new/products.json?limit=4`
- お知らせ: `/pages/news_all.json`
- 記事: `/blogs/product` の公開一覧カード4件
- 動画: `/blogs/movie` の公開一覧カード4件
- 画像: 上記カードが参照する書影・サムネイルのみ、1ファイル3MB以下
- User-Agentを明示し、各リクエスト間に0.8秒の間隔を置く
- 本文、会員限定領域、購入情報、個人情報、検索候補APIは取得しない

出力は `mock/data/live-content.json` と `mock/assets/images/live/` に固定し、
GitHub Pagesの閲覧時には日本医事新報社サイトへのデータ通信を発生させない。
更新頻度は提案期間中の手動更新、または多くても1日1回を上限とする。

## 分類の扱い

現行一覧の表示語をそのまま一つのタグへ押し込まず、デモ側では次の軸へ分離する。

- コンテンツ種別: 書籍、電子版、記事、動画
- 診療領域: 救命救急、脳神経外科、感染症など
- 記事形式: 私の治療、企画、学術・連載、プラタナス
- 日付: 刊行日または公開日

一覧に十分な分類がない場合は「全科共通」とし、推測で細分化しすぎない。
タイトル中の明確な専門領域だけを小さな対応表で補完する。

## トップページのデザイン判断

一般的なストック写真や装飾的な医療画像は使わない。新刊書影、最新記事、
動画見出しを、雑誌の表紙・目次・索引を再解釈した「本日の編集面」にまとめた。
これにより、画像は雰囲気づくりではなく、公開中の情報へ到達する手掛かりになる。

- 背景は白、主色は新報藍 `#174A7E`、濃色は `#0D2C4A`
- グラデーション、多色のカテゴリ分け、常時ループする動きは不使用
- モーションは初回表示時の12px移動と罫線描画だけ
- `prefers-reduced-motion: reduce` では全モーションを停止
- モバイルでは検索を先に、本日の編集面をその下に配置

## 出典とフォールバック

タイトル、日付、公開分類、URL、画像は日本医事新報社の公開ページに由来し、
権利は各権利者に帰属する。デモの詳細ページには公式ページへの明示的なリンクを
置き、本文を複製しない。静的キャッシュが読めない場合だけ
`sample-content.json` に切り替える。
