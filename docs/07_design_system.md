# v6 デザインシステム — 新報藍

## 方針

日本医事新報社のモダナイゼーションを、「歴史を消して医療系SaaSの見た目にすること」とは捉えない。白い紙面、藍の見出し、細い罫線、明朝の編集見出しという出版文化の要素を残し、検索・状態表示・アクセシビリティを現代のWeb品質へ更新する。

画面の仕事は、医師が短時間で情報の種類・鮮度・次の行動を判断できるようにすること。装飾のための色、グラデーション、過剰な影、意味のないアニメーションは使わない。

## カラーパレット

| 名前 | トークン | 値 | 用途 |
|---|---|---|---|
| 紙面白 | `--bg` / `--surface` | `#FFFFFF` | ページ・カード・ヘッダーの基本面 |
| 新報藍 | `--primary` | `#174A7E` | 主要CTA、リンク、現在地、編集罫線 |
| 濃藍 | `--primary-deep` / `--navy` | `#0D2C4A` | フッター、告知帯、強い見出し |
| 淡藍 | `--primary-tint` / `--bg-tint` | `#EAF1F7` | 選択状態、補助情報、空状態 |
| 罫線 | `--line-strong` | `#CEDAE5` | 入力欄・カード・区切り |
| 本文墨 | `--ink` | `#1F2D3D` | 本文と見出し |

### 適用規則

- ゾーン識別は色相を増やさず、ラベル名と見出しで行う。
- 背景は白を基本とし、淡藍は状態や補助説明に限定する。
- カバー画像の代替ビジュアルも新報藍の明度差だけで構成する。
- CSSに`gradient`を含めない。
- 新しい色を追加する場合は、用途とコントラストを本書に追記してから実装する。

## タイポグラフィ

| 役割 | フォント | 用途 |
|---|---|---|
| 編集見出し | 游明朝 / Hiragino Mincho | ロゴ文字、ヒーロー、ページ・セクション見出し |
| UI・本文 | Zen Kaku Gothic New / Noto Sans JP | ナビゲーション、本文、フォーム、カード |
| 数値・英字ラベル | Manrope | 日付、価格、短い英字ラベル |

明朝は出版社としての来歴を示す箇所だけに使う。操作部品と長文本文はゴシックに統一し、可読性と学習しやすさを優先する。

## 形状・余白・動き

- 余白は4px基準の既存スケールを維持する。
- 標準角丸は6px、大きな面でも8pxまで。バッジと円形アイコンだけ例外とする。
- カードは影で浮かせず、1pxの罫線で階層を表す。
- ホバーは色・罫線の変化を基本とし、カード全体を移動させない。
- 動画の再生ボタン、ドロワー開閉など、操作理解に必要な動きだけを残す。
- `prefers-reduced-motion`を常に尊重する。

## シグネチャ

ヒーロー見出しと目的別入口の左に置く「新報藍の縦罫」を、このサイト固有の視覚要素とする。旧来の紙面で情報を区切る罫線を、現代の検索導線・現在地表示として再利用する。意味のない装飾番号や背景模様は加えない。

## コンポーネントの責務

| コンポーネント | 必須情報 | 制約 |
|---|---|---|
| カード | 種別、タイトル、著者等、公開／刊行日、具体的CTA | ゾーンごとに構造を変えない |
| 検索結果 | キーワード、件数、種別タブ、並び順 | 無関係な広告を混在させない |
| ヘッダー | ブランド、主要ゾーン、横断検索、会員導線 | 新しいナビ階層を増やさない |
| 状態表示 | 状態、理由、次の行動 | 読み込み・0件・失敗を別々に扱う |
| フォーム | 永続ラベル、入力支援、エラー、完了状態 | プレースホルダーだけで説明しない |

実装の正本は`mock/assets/css/style.css`。ページ固有色やインラインスタイルを増やさず、このトークンと既存コンポーネントを組み合わせる。
