# IA v7 実装計画と完了記録

更新日: 2026-07-25

## 目的

ヘッダー、検索、トップページ、フッターで反復していた導線を減らし、医療者が「読む・探す・学ぶ・働き方を考える」のどこから入っても迷わない構造へ改める。見た目の刷新ではなく、分類軸と操作の意味を一致させる。

## 実装方針

1. ヘッダーは行動ベースの4入口に限定し、会社情報を主要ナビから外す。
2. トップページの検索フォームは1つだけにする。検索結果ページでは検索語を保持するフォームを1つ置く。
3. 「カテゴリから探す」「目的から探す」「媒体別セクション」の重複を、4つの目的別入口と混合新着一覧へ統合する。
4. 臨床コンテンツと求人・開業情報を検索時点で分離する。
5. `診療領域`、`テーマ`、`記事形式`、`コンテンツ種別`を独立したメタデータとして持つ。
6. 検索対象の切り替えはタブではなく`aria-pressed`を持つスコープボタンにする。
7. 複数選択ファセットは未選択を全件表示とし、選択条件は解除可能なチップとして表示する。
8. カード上の種別ラベルは静的メタデータとし、リンクに見えない操作をなくす。
9. 固定モバイルボトムナビを廃止し、ヘッダーとドロワーに集約する。
10. フッターは利用案内、問い合わせ、企業・方針の3群に限定する。

## 分類モデル

| 軸 | 例 | 主な用途 |
|---|---|---|
| コンテンツ種別 | 記事、書籍、電子版、動画 | 検索スコープ、種別表示 |
| 診療領域 | 循環器内科、救命救急、耳鼻咽喉科 | 階層ナビ、絞り込み |
| テーマ | 診断・治療、検査・診断、診療報酬 | 横断検索、絞り込み |
| 記事形式 | 臨床解説、私の治療、連載、鼎談 | 読み方の選択 |
| シリーズ | 臨床一般、学術・連載 | 継続閲覧 |
| エンティティタグ | 糖尿病、薬剤名、手技名 | 検索補助 |
| 信頼性情報 | 公開日、更新日、著者、監修者 | 医療情報の評価 |

求人は地域・勤務形態・診療科、物件は地域・物件種別を持つ別サービス分類とし、臨床情報の全件検索には初期表示しない。

## デザインシステム

- 背景: `#FFFFFF`
- 主色（新報藍）: `#174A7E`
- 濃藍: `#0D2C4A`
- 淡藍: `#EAF1F7`
- 本文: `#1F2D3D`
- 罫線: `#DCE5ED`
- グラデーションは使用しない。
- 見出しは明朝、本文と操作はゴシックとし、紙媒体の編集秩序を細い罫線と余白で継承する。

## 完了条件

- 全16ページで共通ヘッダー・フッターが同期される。
- トップページ内の検索フォームが1つである。
- `role="tab"`を検索・絞り込み用途に使用していない。
- 初期状態でファセットが全選択されていない。
- JSON、JavaScript、内部リンク、HTML基本構造の静的QAが通る。
- 主要画面をデスクトップ・モバイル幅で目視確認する。
- Private本体とPublic Pagesミラーの双方を更新し、公開ページで反映を確認する。
